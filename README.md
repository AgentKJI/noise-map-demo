# noise-map-demo

This is a simple noise generation example featuring 3 different sliders for the X and Y axis with a Zoom as well. 
Noise is used in procedural generation by getting random locations of this noise map and using the colors to define what gets placed.
For example, the black could be repesenting the land, and the white could be representing the water. 
When doing this, to make it more versatile, you could add a threshold to set how light the color has to be to be known as water and vice versa.
